# Video Player

A desktop video player written in Java with JavaFX. Open a video file from the File menu and control playback with play/pause, forward/backward skip buttons and a seek slider.

## Tech

- Java
- JavaFX - GUI designed in Scene Builder (FXML)
- MediaView / MediaPlayer - video playback

## Features

- Open a video file from the File menu
- Play / pause toggle button
- Forward and backward skip buttons
- Seek slider that follows playback and jumps when dragged
- Menus: File (Open, Save, Exit Player), Tools (Play, Pause, Forward, Backward), Help (About Player)

## Run

Open the VedioPlayer folder as a JavaFX project in IntelliJ IDEA and run sample.Main. Needs a JDK with JavaFX configured.
